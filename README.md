# Visit Bulharsko

Astro verze webu Visit Bulharsko.

## Lokální spuštění

```bash
npm install
npm run dev
```

## Build

```bash
SITE_URL=https://visitbulharsko.cz BASE_PATH=/ npm run build
```

## GitHub Pages preview

Publikuje se z větve `gh-pages`, která obsahuje pouze vygenerovaný `dist/`.

```bash
SITE_URL=https://fikmaxmilian.github.io BASE_PATH=visitbulharsko npm run build
```
